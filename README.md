# «SmartUniver» — Университет студенттері мен оқытушыларына арналған сервистік платформа

## 📌 Жоба туралы
ЖОО студенттері мен оқытушыларына арналған бірыңғай сервистік платформа. Жүйе деканат процестерін (өтініш беру, анықтама алу, секцияларға онлайн жазылу, сабақ және жаттығулар кестесін қарау) цифрландыруға арналған.

---

## 🎯 Жобаның мақсаты (SMART)
- Студенттердің анықтама және жазылу үшін деканатқа физикалық бару санын аптасына 200-ден 80-ге дейін (−60%) азайту.
- Өтініштерді өңдеу уақытын 15–20 минуттан 2–3 минутқа дейін қысқарту.
- Секциялар мен топтардың толықтығын 100% бақылауды қамтамасыз ету.
- Жобаны 15 апта ішінде (семестр соңына дейін) толық енгізу.
